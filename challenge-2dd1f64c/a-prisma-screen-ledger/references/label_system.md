# 标签体系与边界案例约定（prisma-screen-ledger）

## 三态标签

| label | 判定条件（充要） | 必须记录 |
|---|---|---|
| retained | 全部纳入标准命中且无排除标准命中 | 命中的 I 编号、引用原句、置信度 |
| pending | 摘要缺失，或任一纳入标准**无法判定**（信息不足） | 缺失的具体信息、需要什么材料改判、现有部分证据 |
| excluded | 任一排除标准命中 | 命中的 E 编号、引用原句 |

三态是互斥且完备的终态：每条候选恰好一个标签。pending 不是拖延，
而是诚实的信息不足声明； reviewer 可凭 reason 决定是否取全文改判。

## 标准派生模板（PICOS 式，按需裁剪）

- I1 主题：研究主题/干预/暴露与问题核心概念一致（判定字段：标题+摘要）
- I2 对象：研究人群/对象/物种与问题一致（判定字段：摘要）
- I3 设计：研究设计属于问题允许的层级（RCT/队列/病例对照/横断面/
  质性/综述等，按问题写明允许集合）（判定字段：摘要）
- I4 结局/产出：报告了问题关心的结局或证据类型（判定字段：摘要）
- I5 时间：发表时间在问题规定的窗口内（判定字段：year）
- E1 对象不符：人群/物种明确不同（如问题限定人群而研究为小鼠）
- E2 主题不符：核心概念不同（仅共享宽泛词，如“therapy”“study”）
- E3 设计不符：设计明确落在允许集合之外
- E4 语言/可得性排除项（仅当问题声明时启用）
- E5 重复版本：同一研究的另一版本（预印本/会议版/正式版同现）——
  本 Skill 不删除，只标 duplicate_suspect；若问题明确要求版本合并
  才启用，且必须保留 merged_from 证据链

标准写法纪律：动词可判定（“报告了 X”“人群为 Y”），不写
“质量高的”“有意义的”这类不可判定词；每条标准注明所需字段。

## 边界案例处理约定

1. **标题命中关键词但摘要显示对象不符** → excluded(E#)，引用摘要句；
   词面命中不构成相关性。
2. **摘要为空** → 不能 retained；若标题明显排除可 excluded，否则 pending，
   并列入 metadata_gaps。
3. **年份缺失** → I5 无法判定 → pending（除非其余全部排除命中）。
4. **综述/荟萃分析** → 是否纳入由问题的证据层级声明决定；未声明时
   pending 并在 reason 中说明“证据层级未声明”。
5. **同一研究多版本同现** → 各自独立裁决，全部打 duplicate_suspect，
   报告中并排呈现，供人工决定合并。
6. **输入标注冲突**（来源 A 与来源 B 字段矛盾；夹具声明“合成重复导出”）：
   冲突原样保留进 conflicts，说明输入标注是夹具提示而非裁决依据；
   按字段可信度规则（DOI > 正式出版源 > 预印本 > 检索导出）在备注中
   给出倾向，但不静默改写原值。
7. **记录不是论文**（数据集、专利、新闻）→ 按问题意图裁决：问题只要
   论文则 excluded(E2)，reason 说明类型。

## 置信度定义

- high：引用句直接陈述了判定所需事实；
- medium：事实由两句以上间接推出，引用最能支撑的一句；
- low：词面/弱证据冲突，建议人工复核（报告末单列复核清单）。
