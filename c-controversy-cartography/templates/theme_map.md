# 主题图模板（themes.md + review_draft.md 结构）

## themes.md

```markdown
# 主题图

## T1 <主题名>
- 边界：……
- 文档：D1, D4（D2 排除理由：……）
- 共识梯度：已确立 / 有提示 / 有争议（理由一句话）

## T2 <主题名>
- 边界：……
- 文档：D3, D5
- 共识梯度：……
```

同时写 `/app/work/themes_map.json`（机读版，供脚本使用）：

```json
{"T1": ["D1","D4"], "T2": ["D3","D5"]}
```

## review_draft.md（每节结构）

```markdown
## T1 <主题名>
<主题陈述，边界> [C2]
<positive 证据句> [C3;C7]
<negative / 分歧句> [C5] [X1]
<本主题空白> [G2]
共识梯度：有争议（D2 与 D5 结论相反且无法由对象差异解释）。
```

综合结论按梯度分层回答研究问题。
